# Kwvanty Portfolio

A static, responsive, bilingual (English/Ukrainian) developer portfolio.

## Run locally
Open `index.html` in a browser. No build tools, backend, or database are required.

## Customize contact links
Open `script.js` and edit `CONTACT_LINKS` near the bottom:
- `github`: your GitHub profile URL
- `telegram`: your public Telegram link
- `email`: a mailto link, e.g. `mailto:you@example.com`

## Customize content
Most visible text is in the `translations` object in `script.js`.
Project cards are in `index.html`.

## Publish
Upload the contents of this folder to a GitHub repository and enable GitHub Pages
in the repository settings. The site is fully static.
